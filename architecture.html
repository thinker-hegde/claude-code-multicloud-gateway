Quickstart Setup for Developers

1
Set API Keys
Set environment variables in your terminal or OS.
$env:NVIDIA_API_KEY="your_key"
$env:GROQ_API_KEY="your_key"
$env:GEMINI_API_KEY="your_key"
2
Install Deps
Install lightweight proxy dependencies.
pip install -r requirements.txt
3
Run Gateway
Start the multi-cloud auto-failover gateway.
python gateway.py
4
Start Claude Code
Run Claude Code with zero login requirements!
claude

⚡ How the Zero-Login Bypass Works

When you point Claude Code to your local endpoint (http://127.0.0.1:8000) and supply a custom token in ~/.claude/settings.json, Claude Code recognizes that it is running in an enterprise proxy environment and completely skips the browser OAuth login and Anthropic paid subscription flow. Anyone can start coding immediately with 120B models without an Anthropic account!
